# 業務アプリ（まとめ版）

これまで別々だった業務アプリを1つにまとめたものです。
`index.html` をブラウザ（Microsoft Edge / Google Chrome）で開き、**画面上部のタブ**でアプリを切り替えます。
インストールは不要です。

| タブ | アプリ | フォルダ |
| --- | --- | --- |
| 薬剤在庫管理 | 在宅 抗菌薬・解熱鎮痛薬 在庫管理 | `apps/stock/` |
| 在宅移行初期管理料 指示書 | 在宅移行初期管理 指示書作成 | `apps/order/` |
| 訪問リスト印刷 | 患者マスタ取込・訪問患者リスト印刷 | `apps/visit-list/` |
| ワクチン接種管理 | （ファイルを置くと表示されます。下記） | `apps/vaccine/` |
| 持参薬管理 | 持参薬管理 | `apps/jisan/` |

## しくみ

- 各アプリは元のファイルをそのまま `apps/` の下に入れています。**機能・画面・保存形式は元のアプリと同じ**です。
  使い方の詳細は各フォルダの `README.md` を見てください。
- タブは初めて開いたときに読み込み、そのあとは**入力途中の内容を保ったまま**切り替わります。
- 最後に開いていたタブを覚えていて、次回はそのタブから始まります。
  `index.html#jisan` のように `#タブ名`（stock / order / visit-list / vaccine / jisan）を付けて開くと、そのタブから始まります。
- 印刷は各アプリの中の「印刷」ボタンから行ってください。アプリの中身だけが印刷されます（上のタブは印刷されません）。

## これまでのデータ

各アプリは元と同じ保存先（ブラウザ内の localStorage / IndexedDB）を使います。
同じPC・同じブラウザで、元のアプリと同じ開き方（パソコン内のファイルとして開く）をしていれば、これまでのデータがそのまま表示されます。
表示されない場合は、元のアプリ側でバックアップ（書き出し）し、こちらで読み込んでください。

## 通信について

- まとめ用の `index.html` 自体は外部と通信しません。
- 各アプリの通信設定は元のままです（訪問リスト印刷の「訪問ルート（地図）」機能のみ、地図と住所検索で外部に接続します）。

## ワクチン接種管理アプリの追加

`apps/vaccine/` に、ワクチン接種管理アプリのファイル一式を置いてください。
最初に開くファイルの名前を `index.html` にすると、「ワクチン接種管理」タブに表示されます（いま入っている案内用の `index.html` は上書きしてかまいません）。

## タブの追加・変更

`index.html` の中の `APPS` の一覧を編集します（表示名 `label` と、開くファイル `src`）。
