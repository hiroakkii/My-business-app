# 業務アプリ（まとめ版）

これまで別々だった業務アプリを1つにまとめたものです。
`index.html` をブラウザ（Microsoft Edge / Google Chrome）で開き、**画面上部のタブ**でアプリを切り替えます。
インストールは不要です。

| タブ | アプリ | フォルダ |
| --- | --- | --- |
| 薬剤在庫管理 | 在宅 抗菌薬・解熱鎮痛薬 在庫管理 | `apps/stock/` |
| 在宅移行初期管理料 指示書 | 在宅移行初期管理 指示書作成 | `apps/order/` |
| 訪問リスト印刷 | 患者マスタ取込・訪問患者リスト印刷 | `apps/visit-list/` |
| ワクチン接種管理 | ワクチン接種管理 | `apps/vaccine/` |
| 持参薬管理 | 持参薬管理 | `apps/jisan/` |

## しくみ

- 各アプリは元のファイルをそのまま `apps/` の下に入れています。**機能・画面・保存形式は元のアプリと同じ**です。
  使い方の詳細は各フォルダの `README.md` を見てください。
- タブは初めて開いたときに読み込み、そのあとは**入力途中の内容を保ったまま**切り替わります。
- **タブの並び順は自由に変えられます。** タブをつかんで左右にドラッグしてください（タッチ画面では、タブを少し長押ししてから指を滑らせます）。
  並び順は保存され、次回もその順で表示されます。元の順に戻すときは、右端の「並び順を元に戻す」を押します。
  キーボードでは、タブを選んだ状態で `Ctrl` + `Shift` + `←` / `→` で左右に移動できます。
- 最後に開いていたタブを覚えていて、次回はそのタブから始まります。
  `index.html#jisan` のように `#タブ名`（stock / order / visit-list / vaccine / jisan）を付けて開くと、そのタブから始まります。
- 印刷は各アプリの中の「印刷」ボタンから行ってください。アプリの中身だけが印刷されます（上のタブは印刷されません）。

## これまでのデータ

各アプリは元と同じ保存先（ブラウザ内の localStorage / IndexedDB）を使います。
同じPC・同じブラウザで、元のアプリと同じ開き方（パソコン内のファイルとして開く）をしていれば、これまでのデータがそのまま表示されます。
表示されない場合は、元のアプリ側でバックアップ（書き出し）し、こちらで読み込んでください。

## 通信について（セキュリティ）

- まとめ用の `index.html` 自体は外部と通信しません。
- すべてのアプリに Content-Security-Policy（ブラウザに通信先を制限させる設定）を入れています。
  - 薬剤在庫管理・指示書・ワクチン接種管理・持参薬管理：外部への通信を**すべて禁止**。
  - 訪問リスト印刷：国土地理院の地図画像（`cyberjapandata.gsi.go.jp`）と住所検索（`msearch.gsi.go.jp`）**だけ**に限定。
    「① 住所から位置を取得」で住所の文字列（氏名・ID は送りません）を国土地理院に送り、地図を表示した範囲の地図画像を取得します。
    「Googleマップで開く」リンクを押した場合だけ、ルート上の住所（または座標）が Google に渡ります（押さなければ送られません）。
- パソコン内のファイルとして開いた場合、5つのアプリとこの画面は同じブラウザ内の保存領域を使います。
- ブラウザ内のデータとバックアップファイルは、パスワード付きの一括バックアップ以外は暗号化されていません。PC の暗号化（BitLocker など）、
  書き出したファイルの保管場所（ダウンロードフォルダに溜めない、OneDrive の同期対象に入れない）に注意してください。

## バックアップ・データ削除（一括）

画面右上の **「バックアップ・データ削除」** から行います。

- **一括バックアップ**：5つのアプリのデータを1つのファイルに保存します。パスワードを入れると暗号化（AES-GCM）して保存します（忘れると復元できません）。
  郵便番号データ（指示書）と保存先フォルダの設定（ワクチン接種管理）は含みません。
- **一括復元**：一括バックアップのファイルから、各アプリのデータを置き換えて戻します。暗号化したファイルはパスワード欄に入力してから選びます。
- **ブラウザデータの一括削除**：選んだアプリのデータをこのPCのブラウザから削除します（初期設定では、削除の前にバックアップを保存します）。
  ほかのツールのデータや、タブの並び順などのこの画面の設定は削除しません。
- 各アプリ個別のバックアップ・復元・削除の機能も、これまでどおり使えます。

## 患者マスタ（共通）と自動除外

どのアプリも、同じ形式の患者マスタ（Excel）を取り込めます。
見出しは **ID・名前・ふりがな・生年月日・住所・グループホーム・住民票住所・性別** です（各アプリが見出しから列を自動で判別します）。

**訪問リスト印刷以外のアプリ**（薬剤在庫管理・在宅移行初期管理料 指示書・ワクチン接種管理・持参薬管理）では、
取り込むときに次の患者を**自動で除外**します。何名除外したかは取り込み時に表示されます。

- ID に「WA」が入っている患者（全角の「ＷＡ」や小文字も対象）
- 名前に「[亘]」が入っている患者（全角の「［亘］」、「【亘】」「(亘)」も対象。かっこの無い「亘理」などは除外しません）

訪問リスト印刷は、これまでどおり全員を取り込みます。

### 患者マスタ一括取込

画面右上の **「患者マスタ一括取込」** から Excel ファイルを1回選ぶだけで、すべてのアプリの患者マスタにまとめて取り込めます。

1. 「患者マスタ一括取込」を押す
2. 取り込むアプリにチェック（初めは全部。外したアプリは次回も外れたまま）
3. 「ファイルを選んで取り込む」で Excel ファイルを選ぶ → アプリごとの結果（取り込んだ人数・除外した人数）が表示されます

- 中身は、各アプリで「患者マスタ取込」をしたときと同じ処理です（列の自動判別、WA／[亘] の除外、グループホームの判定など）。
  確認画面は自動で「取込」まで進みます。
- 各アプリの患者マスタは、選んだファイルの内容に置き換わります（お守り薬・指示書の履歴・接種記録・持参薬などの登録データは残ります）。
- 列を自動で判別できなかったアプリは ✕ と表示されます。そのタブを開き、取込確認画面で列を指定して取り込んでください。
- 各アプリの個別の「患者マスタ取込」もこれまでどおり使えます。
- しくみ: 各アプリの最後で `apps/common/portal-import.js` を読み込んでいます（アプリを単独で開いたときは何もしません）。

### 住所からグループホームを判定

**訪問リスト印刷**と**ワクチン接種管理**では、住所に「おひさまの家」が含まれている患者を、
グループホーム欄が空でも「おひさまの家」のグループホームの患者として取り込みます
（空白や全角・半角の違いは無視します。グループホーム欄に別の名称が入っている場合はそちらを優先し、「○」などの印だけの場合は「おひさまの家」にします）。
ほかのグループホームも同じようにしたい場合は、`apps/visit-list/app.js` と `apps/vaccine/index.html` の
`GH_NAMES_IN_ADDRESS` に名前を追加します。

※ すでに取り込み済みの患者マスタには自動では反映されません。一度、各アプリで患者マスタを取り込み直してください。
※ 除外の条件は、各アプリの `isExcludedPatient` という関数にあります（`apps/stock/js/app.js`、`apps/order/master.js`、`apps/vaccine/index.html`、`apps/jisan/index.html`）。

## ワクチン接種管理の「バックアップ保存先フォルダ」について

パソコン内のファイルとして開いた場合、Chrome / Edge はタブの中からのフォルダ選択を禁止しています。
そのため、ワクチン接種管理をタブの中で使うときは、`apps/vaccine/portal-fs-bridge.js` が外側の画面（`index.html`）に
フォルダの選択・バックアップの保存・復元一覧の読み込みを代わりに頼むようにしています。使い方は元のアプリと同じです。

- 元のアプリへの変更は、`apps/vaccine/index.html` の最後に `portal-fs-bridge.js` を読み込む1行を足しただけです。
  ワクチン接種管理を単独で開いたときは、この補助は何もしません。
- 保存先フォルダの記録は単独で開いたときと同じ場所を使うので、どちらで設定しても同じフォルダに保存されます。
